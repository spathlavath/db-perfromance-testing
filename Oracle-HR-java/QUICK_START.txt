🔌 HIKARICP CONNECTION POOL
═══════════════════════════════════════════════════════════════════════════════
Both applications use HikariCP with identical configuration:

  Pool Name (V1):          OracleHRPool
  Pool Name (V2):          OracleHRPoolV2
  
  Minimum Idle:            2 connections (configurable via POOL_MIN)
  Maximum Pool Size:       10 connections (configurable via POOL_MAX)
  Connection Timeout:      60 seconds (configurable via POOL_TIMEOUT)
  Idle Timeout:            10 minutes
  Max Connection Lifetime: 30 minutes
  
  Statement Cache:         250 prepared statements
  Cache SQL Limit:         2048 bytes
  Oracle Statement Cache:  25

Environment Variables:
  export POOL_MIN=5
  export POOL_MAX=20
  export POOL_TIMEOUT=60

1. Copy New Relic Agent (if not already present)

   cp /path/to/newrelic.jar /Users/spathlavath/otel/db-perfromance-testing/Oracle-HR-java/

2. Verify Environment Configuration
   ─────────────────────────────────────────────

   # - ORACLE_USER

3. Build and Start
   ─────────────────────────────────────────────
   docker-compose up -d --build
   
4. Check Health
   ─────────────────────────────────────────────

   ─────────────────────────────────────────────
   curl http://localhost:3002/pool-stats | jq .

docker-compose exec oracle-hr-app sh

📁 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Port Conflict (3002 already in use):
  lsof -i :3002
  # If in use, update port in:
  # - application.properties
  # - docker-compose.yml
  # - Dockerfile
  # - test-api.sh

Connection Pool Issues:
  curl http://localhost:3002/pool-stats
  docker-compose logs oracle-hr-app | grep -i "hikari"

Database Connection Failed:
  # Test connection
  docker-compose exec oracle-hr-app curl http://localhost:3002/health
  
  # Verify credentials
  docker-compose exec oracle-hr-app env | grep ORACLE

New Relic Not Reporting:
  # Check agent loaded
  docker-compose logs oracle-hr-app | grep "New Relic Agent"
  
  # Verify license key
  docker-compose exec oracle-hr-app env | grep NEW_RELIC_LICENSE_KEY
  
  # Test collector connectivity
  docker-compose exec oracle-hr-app curl -I https://staging-collector.newrelic.com

Application Won't Start:
  # Check if newrelic.jar exists
  ls -lh newrelic.jar
  
  # View build logs
  docker-compose up --build
  
  # Check for errors
  docker-compose logs oracle-hr-app | grep -i error
